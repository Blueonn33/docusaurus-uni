# Селектори, каскадност и наследственост

## Селектори

Селекторът е шаблон, който се използва за избиране на HTML елементи, които искате да стилизирате. След като бъдат избрани, можете да приложите различни правила за стилизиране (като цвят, размер на шрифта, фон и т.н.) към тези елементи. Селекторите са основна концепция в CSS, тъй като позволяват точно да определите кои елементи да бъдат засегнати от вашите стилове.

### Type Selector

Type Selector - Селекторът за тип (известен още като селектор за елемент) избира всички елементи от даден тип. Например, ако искате да зададете стил на всички абзаци, всички `div` елементи или всички тагове за заглавия, бихте използвали селектора за тип.

```css
p {
    color: red;
}
```

### Class Selector

Class Selector - Селекторът за клас се прилага към елементи, които имат определен атрибут за клас. Класовете се използват за многократна употреба, което означава, че няколко елемента могат да споделят един и същ клас.

За да използвате селектор за клас, поставяте точка (.) пред името на класа:

```css
.my-class {
    background-color: lightblue;
}
```

### ID Selector

ID Selector - Идентификационният селекторът се прилага към елемент, който има конкретен атрибут `id`. За разлика от класовете, ID трябва да бъде уникален в рамките на страницата, което означава, че само един елемент трябва да използва конкретен ID.

За да използвате ID селектор, поставяте символа за диез (#) пред името на ID-то:

```css
#header {
    font-size: 24px;
}
```

### Universal Selector

Universal Selector - Универсалният селектор е насочен към всички елементи на страницата. Той е представен със звездичка (*).

```css
* {
    margin: 0;
    padding: 0;
}
```

### Attribute Selector

Attribute Selector - Атрибутен селектор ви позволява да задавате елементи въз основа на наличието или стойността на конкретен атрибут.

Например, за да изберете всички елементи с атрибута `type="text"`:

```css
input[type="text"] {
    border: 1px solid black;
}
```

### Descendant Selector
Descendant Selector - Наследствен селектор ви позволява да изберете елемент, който е вложен в друг елемент. Той се записва като два селектора, разделени с интервал.

```css
div p {
    color: green;
}
```

Това правило е насочено към всички `<p>` елементи, които са вътре в `<div>`.

### Child Selector

Child Selector - Дъщерният селектор е подобен на наследствения селектор, но е по-специфичен. Той е насочен само към директни деца на даден елемент. Изписва се със символа (>). Директни наследници означава, че те не са вложени в друг елемент. 

```css
div > p {
    color: orange;
}
```

### Adjacent Sibling Selector

Adjacent Sibling Selector - Селекторът на съседния брат е насочен към елемент, който е непосредствено предшестван от друг елемент. Той се пише със знак (+).

```css
h1 + p {
    color: purple;
}
```

Това правило е насочено към първия `<p>` елемент, който идва директно след `<h1>`.

### General Sibling Selector

General Sibling Selector - Общият селектор на братя е насочен към всички елементи, които са братя на даден елемент. Изписва се с тилда (~).

```css
h1 ~ p {
    color: brown;
}
```

Това правило е насочено към всички `<p>` елементи, които са братя на `<h1>`.

## Стилизиране въз основа на състояние

### Псевдокласове селектори
Pseudo-Class Selectors - Псевдокласовете селектори ви позволяват да избирате елементи въз основа на тяхното състояние или позиция. Често срещани псевдокласове включват:

- `:hover` - Насочва се към елемент, когато потребителят задържи курсора на мишката върху него.
- `:nth-child(n)` - Насочва се към елемент въз основа на позицията му в родителски елемент.
- `:focus` - Насочва се към елемент, когато е фокусиран (напр. щракване върху поле за въвеждане на формуляр).

Пример за псевдоклас **hover**

```css
button:hover {
    background-color: lightgray;
}
```

### Pseudo-element selectors
Pseudo-element selector - Псевдоелементите селектори са насочени към специфични части от елемент. Често срещани псевдоелементи включват:

- `::before` - Вмъква съдържание преди елемент.
- `::after` - Вмъква съдържание след елемент.

Пример за използване на **::before** за добавяне на съдържание

```css
h1::before {
    content: "Hellooo ";
}
```
