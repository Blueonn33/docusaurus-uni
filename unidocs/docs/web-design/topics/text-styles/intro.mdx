## Шрифтове

Най-важното за един шрифт е следното:
- Да бъде лесно четим.
- Избор на подходящ цвят.
- Избор на подходящ размер.

**В CSS има 5 семейства шрифтове:**
- **Serif** - Създават усещане за формалност и елегантност.
- **Sans-serif** - Създават модерен и минималистичен вид.
- **Monospace** - Всички букви имат една и съща фиксирана ширина. Те създават механичен вид.
- **Cursive** - Имитират човешкия почерк.
- **Fantasy** - Декоративни и детски шрифтове.

### Добавяне на шрифт

За добавяне на шрифт използваме атрибута `font-family`. Атрибутът трябва да държи няколко имена на шрифтове като резервни, за да се гарантира максимална съвместимост между браузърите/операционните системи. 
Започваме с шрифта, който искаме, и завършваме със семейство. Имената на шрифтовете трябва да бъдат разделени със запетая. Ако името съдържа няколко думи, то трябва да бъде поставено в кавички. 

#### Пример

```css
.p1 {
    font-family: "Times New Roman", Times, serif;
}

.p2 {
    font-family: Arial, Helvetica, sans-serif;
}

.p3 {
    font-family: "Lucida Console", "Courier New", monospace;
}
```

### Стилизиране на шрифта

Използваме атрибутите `font-style` и `font-weight`.

```css
p {
    font-style: normal; 
}
p {
    font-style: italic;
}
```
