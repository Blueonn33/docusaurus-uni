# Стилове за текст

CSS свойствата, използвани за стилизиране на текст, обикновено се разделят на две категории:

**Стилове на шрифта (Font styles)** - Свойства, които влияят на шрифта на текста, например кой шрифт се прилага, неговият размер и дали е удебелен, курсив и др.
**Стилове на оформление на текста (Text layout styles)** - Свойства, които влияят на разстоянието и други характеристики на оформлението на текста, позволявайки манипулиране, например на разстоянието между редовете и буквите и как текстът е подравнен в полето за съдържание. **[[1]](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Text_styling/Fundamentals)**

---

## Шрифтове

Използвайте свойствата за задаване на шрифт в CSS, за да стилизирате текст, да определите неговия размер, удебеляване и семейство от шрифтове. 

Типографията е едно от първите неща, които потребителят забелязва на страницата, а CSS ви дава прецизен контрол върху нея. Свойствата на шрифта в CSS определят шрифта (**семейството шрифтове - font family**), размера, дебелината (**удебелен шрифт**) и стила (**като курсив**) на вашия текст.
