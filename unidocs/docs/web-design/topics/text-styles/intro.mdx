# Стилове за текст

CSS свойствата, използвани за стилизиране на текст, обикновено се разделят на две категории:

**Стилове на шрифта (Font styles)** - Свойства, които влияят на шрифта на текста, например кой шрифт се прилага, неговият размер и дали е удебелен, курсив и др.
**Стилове на оформление на текста (Text layout styles)** - Свойства, които влияят на разстоянието и други характеристики на оформлението на текста, позволявайки манипулиране, например на разстоянието между редовете и буквите и как текстът е подравнен в полето за съдържание. **[[1]](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Text_styling/Fundamentals)**

---

## Шрифтове

Използвайте свойствата за задаване на шрифт в CSS, за да стилизирате текст, да определите неговия размер, удебеляване и семейство от шрифтове. 

Типографията е едно от първите неща, които потребителят забелязва на страницата, а CSS ви дава прецизен контрол върху нея. Свойствата на шрифта в CSS определят шрифта (**семейството шрифтове - font family**), размера, дебелината (**удебелен шрифт**) и стила (**като курсив**) на вашия текст. **[[2]](https://www.w3docs.com/learn-css/css-font)**

CSS свойството `font` е съкращение, което комбинира няколко свойства на шрифта. Ето отделните свойства, които го съставят:

- **[Font Family (Семейство шрифтове)](#font-family)**.
- **[Font Style (Стил на шрифта)](#font-style)**.
- **[Font Size (Размер на шрифта)](#font-size)**.
- **[Font Weight (Дебелина на шрифта)](#font-weight)**.
- **[Font Variant (Вариант на шрифта)](#font-variant)**.

Когато добавяме текст или връзки към уеб страница, ние ги стилизираме, използвайки тези свойства. Нека ги разгледаме подробно.

### Font Family

Използваме свойството `font-family`, за да укажем шрифта за текста. Това определя името на шрифта, използван на уеб страницата.

```css
p {
    font-family: Arial, sans-serif;
}
```

Както можете да видите, приложихме свойството `font-family` към нашия таг `<p>`. Разграничаваме два вида семейства:

- Generic family (общо семейство) - Група от семейства шрифтове с подобен вид (като "Serif" или "Sans-serif").
- Font family (семейство шрифтове) - Определено семейство шрифтове (като "Times New Roman" или "Arial").

:::note
Когато името на **семейство шрифтове** се състои от повече от една дума, оградете я в кавички (напр. "Times New Roman"). Препоръчително е също да предоставите резервно семейство шрифтове, в случай че браузърът не поддържа първото.
:::

### Font Style

Използваме свойството `font-style` предимно за показване на текст в курсив.

Най-често използваните стойности за свойството font-style са:

- **normal** - Показва текста нормално.
- **italic** - Показва текста в курсив.
- **oblique** - Накланя текста.

---

<HtmlPlayground code = {`
<p style="font-style:normal">This is paragraph with font-style property with normal value.</p>
<p style="font-style:italic">This is paragraph with font-style property with italic value.</p>
<p style="font-style:oblique">This is paragraph with font-style property with oblique value.</p>
`} />

---

По подразбиране текстът ни ще бъде с **normal** стил на шрифта, дори без да се записва тази стойност.

### Font Size

Използваме свойството `font-size`, за да зададем размера на текста.

Стойностите могат да бъдат зададени в **pixels**, **points**, **em**, **rem** и др. Можете да намерите пълния списък със стойности в секцията **[font-size](https://www.w3docs.com/learn-css/font-size)**. Обърнете внимание, че 1em е равно на изчисления размер на шрифта на родителския елемент (често 16px по подразбиране). Пикселите (px) са най-често използваната единица.

---

<HtmlPlayground code = {`
<h3 style="font-size:40px;"> Some heading with font-size property.</h3>
<p style="font-size:25px;"> Some paragraph with font-size property.</p>
<a style="font-size:2em;"> Some link with font-size property.</a>
`} />

---

### Font Weight

Сега нека научим как да направим обикновения текст по-удебелен, тъй като заглавията са удебелени по подразбиране.

За това използваме свойството `font-weight`.

Най-често използваните стойности за свойството font-weight са:

- **normal**.
- **bold**.

Стойностите могат да бъдат зададени и като числа.

---

<HtmlPlayground code = {`
<p style="font-weight:900">Some paragraph with the font-weight property with value bold.</p>
<p style="font-weight:normal">Some paragraph with the font-weight property with value normal.</p>
<p style="font-weight:bold">Some paragraph with the font-weight property with value bold.</p>
`} />

---

Числовите стойности варират от 100 до 900. Стойността 400 съответства на нормален шрифт, а 700 съответства на удебелен. С увеличаване на числото от 100 до 900, шрифтът става по-удебелен.

### Font Variant

Свойството `font-variant` ви позволява да зададете текст на нормален или малък регистър (small-caps).

Стойността **small-caps** преобразува малките букви в главни, но ги показва с по-малък размер от оригиналните главни букви.

---

<HtmlPlayground code = {`
<h2>Font-variant property example</h2>
<p>Here we used a normal text as you can see.</p>
<p style="font-variant: small-caps;">But We Used A Text With Small-Caps Here.</p>
`} />

### Font

Вместо да пишете всяко свойство на отделен ред, можете да ги зададете всички наведнъж със съкращението `font`. Това прави вашите стилове по-кратки и групира свързаните декларации заедно.

Редът на стойностите е важен. Синтаксисът е:

```css
font: font-style font-variant font-weight font-size/line-height font-family;
```

Няколко правила, които трябва да запомните:

- **font-size** и **font-family** са задължителни. Ако някой от тях липсва, цялата декларация се игнорира.
- **font-style**, **font-variant**, and **font-weight** са незадължителни и трябва да са преди **font-size**.
- **line-height** е незадължителна и се пише след **font-size**, разделена с наклонена черта (/).
- Всяка стойност, която пропуснете, се връща към стойността си по подразбиране, така че съкратеният вариант е удобен начин за изчистване на по-ранни декларации с пълен вариант.

```css
/* Longhand */
p {
  font-style: italic;
  font-weight: bold;
  font-size: 18px;
  line-height: 1.5;
  font-family: Georgia, serif;
}

/* Equivalent shorthand */
p {
  font: italic bold 18px/1.5 Georgia, serif;
}
```

## Текст

CSS ви дава прецизен контрол върху това как изглежда текстът. Разгледани са основните свойства, които се прилагат върху текст.

- **[Text Color (Цвят на текста)](#text-color)**.
- **[Text Alignment (Подравняване на текста)](#text-alignment)**.
- **[Text Decoration (Декорация на текста)](#text-decoration)**.
- Text Transform (Трансформация на текста).
- Text Shadow (Сянка на текста). 
- Text Indentation (Отстъп на текста).
- Letter Spacing (Разстояние между буквите).
- Line Height (Височина на реда).
- Word Spacing (Разстояние между думите).

### Text Color

Свойството `color` задава цвета на текста на елемента (и по подразбиране, неговите текстови декорации, като например подчертавания - underlines). Можете да зададете стойността като цвят (red), HEX стойност (#ff0000), стойност на rgb() / rgba() (rgb(255 0 0)) или hsl() стойност. Тъй като цветът се наследява, задаването му върху контейнер го прилага към целия наследен текст, освен ако наследен елемент не го презапише.

---

<HtmlPlayground code = {`
<p style="color:#ff0000">This is some paragraph in red.</p>
`} />

---

### Text Alignment

Свойството `alignment` се използва за подравняване на текст вътре в елемент вляво, вдясно, в центъра и т.н.

Подравняването на текст има четири стойности:

- **Left (text-align: left)** - Подравнява текста вляво.
- **Right (text-align: right)** - Подравнява текста вдясно.
- **Center (text-align: center)** - Поставя текста в центъра на страницата.
- **Justify (text-align: justify)** - Разтяга реда с текст, за да подравни и левия, и десния край (както в списания и вестници).

По подразбиране браузърите подравняват текста в началото на реда - вляво. Използвайте съответстващата стойност, когато се нуждаете от различно подравняване.

---

<HtmlPlayground code = {`
<p>This is some paragraph</p>
<p style="text-align:center">Some paragraph with value center.</p>
<p style="text-align:right">Some paragraph with value right.</p>
<p style="text-align:justify">Some paragraph with value justify.</p>
`} />

---

### Text Decoration

Свойството `text-decoration` добавя линии към текста. В съвременния CSS това е съкращение за **text-decoration-line**, **text-decoration-color** и **text-decoration-style**. Най-често срещаните стойности за частта text-decoration-line са:

- **Overline (text-decoration: overline)** - Чертае линия над текста.
- **Underline (text-decoration: underline)** - Чертае линия под текста.
- **Line-through (text-decoration: line-through)** - Чертае линия през средата на текста.
- **None (text-decoration: none)** - Премахва всякаква декорация; това е, което използвате, за да премахнете подчертаването по подразбиране от хипервръзките.

---

<HtmlPlayground code = {`
<a style="text-decoration:none">This is link without underline</a>
<h1 style="text-decoration:overline">Heading with value overline.</h1>
<p style="text-decoration:line-through">Some paragraph with value line-through.</p>
<a style="text-decoration:underline">Some hyperlink with value underline.</a>
`} />
