# Стилове за текст

CSS свойствата, използвани за стилизиране на текст, обикновено се разделят на две категории:

**Стилове на шрифта (Font styles)** - Свойства, които влияят на шрифта на текста, например кой шрифт се прилага, неговият размер и дали е удебелен, курсив и др.
**Стилове на оформление на текста (Text layout styles)** - Свойства, които влияят на разстоянието и други характеристики на оформлението на текста, позволявайки манипулиране, например на разстоянието между редовете и буквите и как текстът е подравнен в полето за съдържание. **[[1]](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Text_styling/Fundamentals)**

---

## Шрифтове

Използвайте свойствата за задаване на шрифт в CSS, за да стилизирате текст, да определите неговия размер, удебеляване и семейство от шрифтове. 

Типографията е едно от първите неща, които потребителят забелязва на страницата, а CSS ви дава прецизен контрол върху нея. Свойствата на шрифта в CSS определят шрифта (**семейството шрифтове - font family**), размера, дебелината (**удебелен шрифт**) и стила (**като курсив**) на вашия текст. **[[2]](https://www.w3docs.com/learn-css/css-font)**

CSS свойството `font` е съкращение, което комбинира няколко свойства на шрифта. Ето отделните свойства, които го съставят:

- **[Font Family (Семейство шрифтове)](#font-family)**.
- **[Font Style (Стил на шрифта)](#font-style)**.
- **[Font Size (Размер на шрифта)](#font-size)**.
- Font Weight (Дебелина на шрифта).
- Font Variant (Вариант на шрифта).

Когато добавяме текст или връзки към уеб страница, ние ги стилизираме, използвайки тези свойства. Нека ги разгледаме подробно.

### Font Family

Използваме свойството `font-family`, за да укажем шрифта за текста. Това определя името на шрифта, използван на уеб страницата.

```css
p {
    font-family: Arial, sans-serif;
}
```

Както можете да видите, приложихме свойството `font-family` към нашия таг `<p>`. Разграничаваме два вида семейства:

- Generic family (общо семейство) - Група от семейства шрифтове с подобен вид (като "Serif" или "Sans-serif").
- Font family (семейство шрифтове) - Определено семейство шрифтове (като "Times New Roman" или "Arial").

:::note
Когато името на **семейство шрифтове** се състои от повече от една дума, оградете я в кавички (напр. "Times New Roman"). Препоръчително е също да предоставите резервно семейство шрифтове, в случай че браузърът не поддържа първото.
:::

### Font Style

Използваме свойството `font-style` предимно за показване на текст в курсив.

Най-често използваните стойности за свойството font-style са:

- **normal** - Показва текста нормално.
- **italic** - Показва текста в курсив.
- **oblique** - Накланя текста.

---

<HtmlPlayground code = {`
<p style="font-style:normal">This is paragraph with font-style property with normal value.</p>
<p style="font-style:italic">This is paragraph with font-style property with italic value.</p>
<p style="font-style:oblique">This is paragraph with font-style property with oblique value.</p>
`} />

---

По подразбиране текстът ни ще бъде с **normal** стил на шрифта, дори без да се записва тази стойност.

### Font Size

Използваме свойството `font-size`, за да зададем размера на текста.

Стойностите могат да бъдат зададени в **pixels**, **points**, **em**, **rem** и др. Можете да намерите пълния списък със стойности в секцията **[font-size](https://www.w3docs.com/learn-css/font-size)**. Обърнете внимание, че 1em е равно на изчисления размер на шрифта на родителския елемент (често 16px по подразбиране). Пикселите (px) са най-често използваната единица.

---

<HtmlPlayground code = {`
<h3 style="font-size:40px;"> Some heading with font-size property.</h3>
<p style="font-size:25px;"> Some paragraph with font-size property.</p>
<a style="font-size:2em;"> Some link with font-size property.</a>
`} />

---

### Font Weight

Сега нека научим как да направим обикновения текст по-удебелен, тъй като заглавията са удебелени по подразбиране.

За това използваме свойството `font-weight`.

Най-често използваните стойности за свойството font-weight са:

- **normal**.
- **bold**.

Стойностите могат да бъдат зададени и като числа.

---

<HtmlPlayground code = {`
<p style="font-weight:900">Some paragraph with the font-weight property with value bold.</p>
<p style="font-weight:normal">Some paragraph with the font-weight property with value normal.</p>
<p style="font-weight:bold">Some paragraph with the font-weight property with value bold.</p>
`} />
