# HTML изображения

HTML тагът `<img>` се използва за вграждане на изображения в уебстраници чрез създаване на връзка към тях. Той създава място за изображението, дефинирано чрез атрибути като `src`, `width`, `height` и `alt`, и не изисква затварящ таг.

Съществуват два начина за вмъкване на изображения в уебстраница:
Чрез посочване на пълен път или адрес (URL) за достъп до файл в интернет.
Чрез посочване на път до файла, определен спрямо местоположението на текущата уебстраница.
