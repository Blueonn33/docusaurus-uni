# Въведение в CSS

CSS - Cascading Style Sheets (каскадни стилови таблици) е език, който ви позволява да създавате страхотно изглеждащи уеб страници. **[[1]](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/What_is_CSS)**

Тук можете да прочетете **[[допълнителна информацията]](https://developer.mozilla.org/en-US/docs/Web/CSS)** за CSS.

---

## Стиловe по подразбиране на браузъра

Вече разгледахме какво е HTML и как се използва в документи. Тези документи ще бъдат четими в уеб браузър. Заглавията ще изглеждат по-големи от обикновения текст, абзаците ще се разделят на нов ред и ще имат интервал между себе си. Връзките са оцветени и подчертани, за да се различат от останалия текст.

Тези стилове са дефинирани в CSS стилови таблици по подразбиране, съдържащи се в браузъра – те нямат нищо общо с HTML.

## За какво се използва CSS?

С помощта на CSS можете да контролирате как точно изглеждат HTML елементите в браузъра, представяйки документите си на потребителите с какъвто и да е дизайн и оформление, които желаете.

- Документът обикновено е текстов файл, структуриран с помощта на език за маркиране, най-често HTML (тези се наричат ​​HTML документи). Може да попаднете и на документи, написани на други езици за маркиране, като SVG или XML. HTML документът съдържа съдържанието на уеб страница и определя нейната структура.
- Представянето на документ на потребител означава преобразуването му във форма, използваема от вашата аудитория. Браузъри като **Comet**, **Firefox**, **Chrome**, **Safari** и **Edge** са предназначени да представят документи визуално, например на компютърен екран, проектор, мобилно устройство и т.н. В уеб контекст това обикновено се нарича **рендиране (rendering)**. Ако искаш да прочетеш за процеса, чрез който се рендира уеб страница, [[ето линк]](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_browsers_load_websites).

CSS може да се използва за много цели, свързани с външния вид на вашата уеб страница, например:
- Стилизиране на текст, включително промяна на цвета и размера на заглавия и връзки.
- Създаване на оформления, като например мрежови оформления (grid layouts) или оформления с няколко колони (multiple-column layouts).
- Специални ефекти като например анимация.

## CSS синтаксис

CSS е език, базиран на правила — дефинирате правила, като посочвате групи стилове, които трябва да се приложат към определен елемент или групи елементи на вашата уеб страница.

Например, може да решите да стилизирате главния заглавен текст на страницата си като голям червен текст. Следният код показва много просто CSS правило, което би постигнало това:

```css
h1 {
    color: red;
    font-size: 2.5em;
}
```

- В горния пример, CSS правилото се задава със селектор. **[CSS селекторът](https://developer.mozilla.org/en-US/docs/Glossary/CSS_Selector)** е частта от CSS правило, която описва кои елементи в документа ще съответстват на правилото. Към съответстващите елементи ще бъде приложен зададения от правилото стил. В този случай стилизираме заглавия от ниво едно (`<h1>`).
- След това включваме набор от къдрави скоби ({ }), за да създадем блок за декларации.
- Блокът за декларации съдържа една или повече декларации, които са под формата на двойки **свойство** и **стойност**. Указваме свойството (например, цвят в горния пример) преди двоеточието и указваме стойността на свойството след двоеточието (червено е стойността, която се задава за свойството цвят).
Този пример съдържа две декларации, едната за цвят и другата за размер на шрифта.

Различните CSS свойства имат различни допустими стойности. В нашия пример имаме свойството **color**, което може да приема различни стойности за цвят. Също така имаме свойството **font-size**. Това свойство може да приема различни мерни единици за размер като стойност. CSS стиловият лист съдържа много такива правила, написани едно след друго.

```css
h1 {
    color: red;
    font-size: 2.5em;
}

p {
    color: aqua;
    padding: 5px;
    background: midnightblue;
}
```

:::info
Можете да намерите връзки към всички страници със свойства на CSS (заедно с други CSS функции), изброени в **[справочника за CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference)** на MDN. Като алтернатива, трябва да свикнете да търсите „mdn css-feature-name“ в любимата си търсачка, когато имате нужда от повече информация за дадена CSS функция. Например, опитайте да търсите „mdn color“ или „mdn font-size“!
:::

## Прилагане на CSS към HTML документ

Когато отворите уеб страница, браузърът първо получава HTML документа, съдържащ съдържанието на уеб страницата, и го преобразува в DOM дърво.

След това всички CSS правила, намерени в уеб страницата (или вмъкнати директно в HTML, или в посочени външни .css файлове), се сортират в различни **кофи (buckets)**, въз основа на различните елементи, към които ще бъдат приложени (както е посочено от техните селектори). След това CSS правилата се прилагат към DOM дървото, което води до дърво за рендериране, което след това се изобразява в прозореца на браузъра.

Нека разгледаме един пример. Първо, ще дефинираме HTML фрагмент, към който може да се приложи CSS кодът:

---
<HtmlPlayground code = {`
<h1>CSS is great</h1>
<p>You can style text.</p>
<p>And create layouts and special effects.</p>
`}/>
---

След това и CSS кодът:

```css
h1 {
    color: red;
    font-size: 2.5em;
}
p {
    color: aqua;
    padding: 5px;
    background: midnightblue;
}
```

Този CSS код:

- Избира всички `<h1>` елементи на страницата, оцветявайки текста им в червено и правейки ги по-големи от размера им по подразбиране. Тъй като в нашия примерен HTML код има само един `<h1>`, само този елемент ще получи стилизацията.
- Избира всички `<p>` елементи на страницата, като им дава цветен текст и цвят на фона, както и известно разстояние около текста. В нашия примерен HTML код има два `<p>` елемента и двата получават стилизацията.

<HtmlPlayground code = {`
<style>
h1 {
        color: red;
        font-size: 2.5em;
}
p {
        color: aqua;
        padding: 5px;
        background: midnightblue;
}
</style>

<h1>CSS is great</h1>
<p>You can style text.</p>
<p>And create layouts and special effects.</p>
`}/>

Нека разгледаме пример. Първо, ще дефинираме HTML фрагмент, към който CSS може да се приложи:

Когато използвате CSS, първото нещо, което трябва да направите правилно, е да се уверите, че вашият CSS е успешно приложен към вашия HTML код. В този раздел ще добавим CSS стилове към вашата страница. **[[2]](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Styling_the_content)**

- Създайте си файл `index.html`. След това сложете един `<p>` елемент, съдържащ някакъв текст.
- Продължаваме със следващия файл - `styles.css`. В него сложете следния код:

```css
p {
  color: red;
}
```

- За да приложим стиловете към HTML документа, трябва да укажем връзка към `styles.css` файла. Това се осъществява чрез `<link href="style.css" rel="stylesheet" />`

Имаме следния HTML код:

---

Ако добавим малко CSS, можем да променим начина, по който изглежда HTML съдържанието. Следният фрагмент избира елемента `<p>` и му дава различен шрифт и червен цвят на текста. След това избира всички елементи `<li>` и дава на всеки от тях зелено-жълт цвят на фона, плътна черна рамка от 1 пиксел и долен margin от 5 пиксела:

```css
p {
  font-family: sans-serif;
  color: red;
}

li {
  background-color: greenyellow;
  border: 1px solid black;
  margin-bottom: 5px;
}
```
